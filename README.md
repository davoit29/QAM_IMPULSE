# Симуляция QAM Модуляции и AWGN канала

Данный проект представляет собой программный комплекс на языке C++ для моделирования цепочки передачи цифрового сигнала: **Генерация бит → Модуляция → Добавление шума → Демодуляция**.



## Особенности
- Поддержка трех типов модуляции: **QPSK (4-QAM)**, **16-QAM**, **64-QAM**.
- Реализация **AWGN-канала** (аддитивный белый гауссовский шум) с использованием  генератора `std::mt19937`.
- Демодуляция 
- Автоматический сбор данных в формате `.csv` для последующего анализа.
- Скрипт на Python для визуализации результатов (построение кривых BER).

## Структура проекта
- `include/` — заголовочные файлы (.h) с описанием интерфейсов классов.
- `src/` — реализация логики на C++ (.cpp) и основной управляющий файл `main.cpp`.
- `python/` — скрипт для построения графиков.
- `results.csv` — генерируемые данные симуляции.

## Математическая модель
Симуляция базируется на модели канала с комплексным аддитивным шумом:
$$r = s + n$$
где $s$ — идеальный символ созвездия, а $n$ — комплексный шум, дисперсия которого делится поровну между вещественной (I) и мнимой (Q) составляющими.

## Запуск проекта

### 1. Требования
- Компилятор C++ (поддержка C++11 и выше, например, `g++`).
- Python 3.x с библиотеками `pandas` и `matplotlib`.

### 2. Сборка и запуск симуляции
Выполните следующие команды в терминале из корневой папки проекта:

```bash
# Компиляция проекта
g++ src/main.cpp src/Modulator.cpp src/Channel.cpp src/Demodulator.cpp -I include -o simulation.exe

# Запуск симуляции (создаст results.csv)
./simulation.exe
